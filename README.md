# Contexto
Ejercicios practicos en lenguaje sql  donde se toma como ejemplo  un restaurante que lanzó un nuevo menú a principios de año y ha estado recopilando
 información detallada sobre las transacciones de los clientes para identificar áreas de
 oportunidad y aprovechar al máximo sus datos para optimizar las ventas.
## Objetivo
poner en practica lo aprendido en el modulo de sql del curso analisis de datos al identificar  los productos del menú que han tenido más éxito y cuales son los
 menos han gustado a los clientes.
